# MS-GIS
My GIS Tools

Open-source GIS tools developed for practical use in **GIS, surveying, civil engineering, hydraulic engineering, and geospatial analysis**.

This repository contains standalone **HTML/JavaScript-based GIS tools** that can be opened directly in a web browser without installing specialized GIS software.

## 🌐 GIS Tools

| Tool                          | Description                                                              | Open Tool                                                                              |
| ----------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| **UTM Grid Console**          | Generate, visualize, and work with UTM grid information and coordinates. | [🚀 Open Tool](https://msk1991-py.github.io/MS-GIS/UTM_Grid_Console.html)              |
| **UTM Grid Console – Source** | HTML/JavaScript source code                                              | [📄 View Source](https://github.com/msk1991-py/MS-GIS/blob/main/UTM_Grid_Console.html) |

## 🚀 How to Use

Most tools in this repository are designed as **standalone web applications**.

1. Open the **Open Tool** link.
2. Use the tool directly in your browser.
3. No installation is normally required.
4. The tools are intended for open-source use and practical GIS workflows.

You can also download the `.html` file and run it locally by opening it in a modern web browser.

The objective is to keep the tools **lightweight, transparent, portable, and easy to use**.
